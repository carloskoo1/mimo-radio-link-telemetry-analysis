# V19 Article: Retrospective segment-sensitivity audit

**Scope:** Post hoc descriptive reanalysis of the archived hourly panel from the Jhon Cristhian Torres Hoyos undergraduate thesis, not a new campaign or a registered confirmatory experiment.

## Input and provenance

- Source panel: `03_dataset_horario.parquet`, generated by the archived thesis processing pipeline.
- SHA-256: `977d95ec7328edc5bc881c0ebd944ced044d2724a5ede8c5f8be7e43a65a981b`.
- Source panel: 2,023 hourly rows; 1,989 analytical rows after requiring `delta_rssi_primary`, `snr_dl`, `snr_ul`, `mcs_dl`, `mcs_ul` and `dl_rate_mbps` all non-missing.
- 89 dates with at least one complete hourly analytical record; four uninterrupted **date runs**, built from consecutive dates with complete observations. Source files exist for 90 dates; the difference is not automatically a link outage.
- Data remain on the authorized research system and are **not published in this Git repository**.

## Reproduction

Install compatible versions of Python, pandas, scipy and pyarrow in a separate analysis environment. Run:

```sh
python analysis/article_segment_sensitivity_v19.py --input /authorized/path/03_dataset_horario.parquet
```

The script rejects unrecognized dataset hashes by default, checks the reference dimensions, and prints only aggregate JSON. It does not modify the source dataset.

## Field semantics verified from source acquisition script

The archived SSH script queries the AP with `show rssi` and parses `chain 0 RSSI primary` and `chain 1 RSSI primary`. It separately queries `show sta` and parses `connectedSTADLRateMbps`. The collected AP/SM-labeled CSV rows replicate shared fields; these are not independent AP and SM receiver measurements. Historical firmware-specific mapping of `show rssi` chain metrics to radio-link direction has not been established. The DL rate is vendor-reported PHY state, not saturated capacity or application goodput.

## Interpretation boundary

All segment and leave-one-segment-out analyses are retrospective, descriptive, and based on repeated measurements from **one fixed link**. Their positive sign is not evidence of causation, greater beneficial imbalance, receiver calibration, a universal fault threshold, or cross-link generalization. The reviewer-facing manuscript discloses this limitation. The older seven-day moving-block intervals reported in the thesis are a separate post hoc sensitivity exercise, not segment-specific confidence intervals.
